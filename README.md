# CFNew 修改版

本项目基于 [cfnew](https://github.com/byJoey/cfnew) 的 `2.9.7` 和`2.9.8`版本进行修改，支持使用明文代码直接部署。

## 2.9.7主要修改(已失效，会被检测到)

- **移除波斯文** – 界面不再包含波斯语支持。
- **去除延迟检测功能** – 不再进行网络延迟检测。
- **调整默认配置并在前端移除设置**：
  - 允许 API 管理 → **默认关闭**
  - 地区匹配 → **默认启用**
  - 降级控制 → **默认不启用**
  - TLS 控制 → **默认为仅 TLS**
  - 优选控制 → **默认启用**


## 2.9.8主要修改（已失效，会被检测到）

- **移除波斯文** – 界面不再包含波斯语支持。
- **调整默认配置**：
  - 允许 API 管理 → **默认关闭**
  - 地区匹配 → **默认启用**
  - 降级控制 → **默认不启用**
  - TLS 控制 → **默认为仅 TLS**
  - 优选控制 → **默认启用**
  - TLS ALPN → **默认使用h3**
  - 默认启用vless和trojan
  - 默认启用 ECH (Encrypted Client Hello)



## 使用说明

可直接使用明文代码部署，无需混淆
